## About Me

I am an AI Engineer focused on building intelligent applications and systems that interact with the real world.

My work combines **Agentic AI, Retrieval-Augmented Generation (RAG), knowledge engineering, computer vision, deep learning and robotics**.

I enjoy engineering complete solutions — from designing multi-agent workflows and retrieval pipelines to deploying vision models and integrating microcontrollers, cameras and motors.

I also have experience teaching robotics and AI, mentoring students, and developing hands-on technical projects.

- Building agentic workflows with **LangGraph and LLMs**
- Developing knowledge retrieval systems with **Qdrant and Pinecone**
- Working on computer vision, image classification and segmentation
- Exploring embedded AI, ESP32, Raspberry Pi and robotics
- Interested in scalable AI applications and edge deployment

### 01 · Enterprise IT Support Agentic RAG



An agentic IT support knowledge system that retrieves relevant information, evaluates evidence and uses web search when additional information is required.

**Technology:** `Python` `LangGraph` `FastAPI` `Pinecone` `Groq` `Tavily`

[View repository →](https://github.com/MrAvishek/Enterprise_IT_Support_Agentic_RAG)

### 02 · HRNexus — Enterprise HR Knowledge Agent



An AI-powered knowledge agent designed to retrieve and work with information from enterprise HR documents using retrieval and agentic workflows.

**Technology:** `Python` `LangGraph` `Qdrant` `RAG`

[View repository →](https://github.com/MrAvishek/HRNexus-Enterprise-HR-Knowledge-Agent)

### 03 · Landslide Detection using Deep Learning



A deep-learning segmentation system for identifying landslide regions in satellite imagery using the Landslide4Sense dataset and a U-Net architecture.

**Technology:** `Python` `TensorFlow` `U-Net` `FastAPI` `Satellite Imagery`

[View repository →](https://github.com/MrAvishek/Landslide-Detection-by-satellite-image-processing-with-Deep-learning-)

### 04 · Solar Panel Condition Classifier



An image classification application that identifies six solar panel conditions using EfficientNetB0, with a Streamlit interface deployed on AWS EC2.

**Technology:** `TensorFlow` `Keras` `EfficientNetB0` `Keras Tuner` `Streamlit` `AWS EC2`

[View repository →](https://github.com/MrAvishek/Panel-Classifier)

### 05 · ESP32-CAM Surveillance Robot



A camera-enabled surveillance robot combining embedded programming, wireless communication and motor control.

**Technology:** `ESP32-CAM` `Embedded C++` `Wi-Fi` `Motor Control`

[Repository](https://github.com/MrAvishek/ESP-32-cam-Based-Surveillance-Robot-) · [Watch demo](https://drive.google.com/file/d/1EZhBB7vqIVUU9zlKo6yndRyvZQyGgQO8/view?usp=drive_link)

### 06 · ESP8266 MiniGameServer



An ESP8266-based local server that creates its own Wi-Fi hotspot and hosts browser-based games.

**Technology:** `ESP8266` `Arduino` `Wi-Fi` `Web Server`

[View repository →](https://github.com/MrAvishek/MiniGameServer)
